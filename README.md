# Independent Palestine: View to the Future

A single-page conference website built as a Frontend practical exam project. The site presents a conference bringing together historians, diplomats, and humanitarian experts to discuss the political, economic, and social dimensions of Palestinian independence.

## Description

The site includes a hero section with a live countdown timer to the conference date, an about section with program highlights, a speakers section with dynamically generated cards, and a registration form with full validation and data persistence.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Bootstrap 5
- JavaScript (ES6+)
- Git & GitHub
- localStorage

## Features

- Speaker cards generated dynamically from a JavaScript array using map()
- "Add to my schedule" button on each speaker card, saved to localStorage and persisted across page reloads
- Program highlights list built dynamically with forEach()
- Live countdown timer to the conference date using recursive setTimeout()
- Registration form with:
  
        - Empty field validation
        - Email format validation
        - Error messages per field
        - Success message on valid submission
        - Form data saved to localStorage
- Fully responsive layout (Flexbox + CSS Grid + media queries)
